HOW TO READ THIS

The axis with the largest recorded absolute acceleration is identified as the strongest axis during the current monitoring session.

Values are measured relative to the sensor's fixed X, Y and Z directions.

First press saves the session and resets live values. Second press opens the iPhone Share sheet: choose Save to Files.
IPHONE EXPORT HELP
After the second press, choose Save to Files in the iPhone Share sheet. Save the .xlsx file in On My iPhone or iCloud Drive. If Excel export is unavailable, the page creates an Excel-compatible .csv file instead.
